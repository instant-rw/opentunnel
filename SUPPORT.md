# Support

OpenTunnel is maintained as a personal, source-available project. Support is
best-effort and no response time is guaranteed.

## Before asking for help

1. Read the [documentation](README.md#documentation) and
   [troubleshooting guide](docs/troubleshooting.md).
2. Search existing GitHub issues.
3. Confirm the problem still occurs on the latest supported version.
4. Collect a minimal reproduction and sanitized logs.

Use a GitHub issue for reproducible bugs and focused feature requests. Include
your OpenTunnel version or commit, operating system, relevant configuration
with secrets removed, expected behavior, actual behavior, and reproduction
steps.

Do not post credentials, tokens, `.env` contents, personal data, database
dumps, or captured private traffic.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md), not through a public issue.
